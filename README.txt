BHUPINDER & JORIEN — WEDDING INVITATION WEBSITE

FILES
- index.html                Main invitation page
- assets/floral-top.svg     Top-left floral artwork
- assets/floral-bottom.svg  Bottom-right floral artwork
- assets/botanical-divider.svg Decorative divider
- assets/favicon.svg        Browser-tab icon
- assets/social-banner.svg   1200x630 share/banner artwork
- assets/bhupinder-jorien-wedding.ics Calendar file for Friday + Saturday

UPLOAD
Upload index.html and the entire assets folder together, preserving the folder structure.

RSVP EMAIL (OPTIONAL)
The page works without a server: guests complete the form and click "Create RSVP message", then copy or share the generated message.
If you want an Email RSVP button, open index.html and find:
  const RSVP_EMAIL = "";
Add your email address between the quote marks.

HOSTING
This is a static website. It can be hosted on almost any web host, GitHub Pages, Netlify, Cloudflare Pages, or your own hosting package.

NOTES
- Mobile responsive.
- Countdown is set to 11:00 on 7 August 2027 in Netherlands summer time (+02:00).
- Motion automatically reduces for visitors who have "reduced motion" enabled.
- Decorative animations use modern HTML/CSS/JavaScript, not the obsolete Adobe Flash plugin.
